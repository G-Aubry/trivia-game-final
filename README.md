# Terminal Trivia

Question format - 
Category | Type | Question | Correct Answer | Option 1 | Option 2 |... 
Category = Subject.
Type = MC (has all 4) or TF (Option 3/4 included but not selectable).
Question = Text to display.
Options = Selectable answers, randomized in display question.
Correct Answer = Exact Match to one of the options.
